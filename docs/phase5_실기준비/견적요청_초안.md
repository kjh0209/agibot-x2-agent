# X2 Ultra 견적 요청 초안 (이메일/문의폼용)

수신: AgiBot 공식 스토어(store.agibot.com) 문의 채널 또는 국내 총판

---

제목: AgiBot X2 Ultra 구매 견적 요청 (연구/개발 용도)

안녕하세요. 휴머노이드 로봇 기반 대화형 에이전트 시스템을 개발 중인
개발자입니다. X2 Ultra Edition 구매를 검토하고 있어 견적을 요청드립니다.

1) 대상 모델: AgiBot X2 **Ultra Edition** (SDK 2차 개발 지원 모델)
2) 수량: 1대
3) 배송지: 대한민국 (정확한 주소는 계약 시 전달)
4) 확인 요청 사항:
   - 본체 가격 및 KRW/USD 결제 조건
   - 한국 배송비, 예상 리드타임 (발주→입고)
   - 관세/부가세 처리 방식 (DDP 여부)
   - 워런티 범위와 기간 — 특히 **낙상/충돌로 인한 파손의 커버 여부**,
     유상 수리 시 대략적인 비용 수준
   - 예비 배터리 단가, 자동충전독(옵션) 단가
   - 펌웨어/SDK 기술지원 채널 (개발 중 문의 대응)
   - 결제 조건 (선금 비율, 잔금 시점)
5) 참고: 시뮬레이션 기반으로 에이전트 소프트웨어를 선행 개발 완료한
   상태이며(AimDK v1.0.0 기준), 입고 후 즉시 SDK 개발 예정입니다.

회신 주시면 감사하겠습니다.
