## E. 안전 수칙 (모든 실기 세션 공통)

- 역할: 조작자 1인 + **리모컨 파지 대기 1인** (비상 시 damping → zero-torque)
- 비상 절차: L2+R2+Create(damping) → L1+R1+Create(zero-torque).
  zero-torque는 로봇이 무너짐 — 갠트리 매달림 상태 또는 낙하 대비 필수
- 세션 중단 조건: 배터리 <30%, 리모컨 배터리 경고, 관절 이상음/발열,
  예측 불가 거동 1회라도 발생 시
- 제어 소스 전환 최소화 (rc↔app↔agent 잦은 전환 금지 — 전도 위험)
- 에이전트 이동 상한: vx 0.3m/s / 3초 유지 (코드 강제) — 완화는
  갠트리 검증 후 단계적으로
