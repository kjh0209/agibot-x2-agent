# 실기 네트워크 설정 (Phase 5-6용, 공식 문서 기준)

## 유선 직결 (개발 권장)

- 개발 PC ↔ 로봇 등쪽 RJ45 (기가비트, 2포트 중 아무거나)
- 개발 PC 고정 IP: **10.0.1.2/24**
- 접속 대상:
  - PC2 (개발용, Orin NX): **10.0.1.41** ← 우리가 쓰는 곳
  - PC1 (모션제어 MCCU): 10.0.1.40 — **빌드/실행 절대 금지** (공식 명문)

### macOS에서 고정 IP (USB-이더넷 어댑터 기준)
```bash
# 인터페이스 이름 확인
networksetup -listallhardwareports
# 고정 IP 설정 (예: USB 10/100/1000 LAN)
sudo networksetup -setmanual "USB 10/100/1000 LAN" 10.0.1.2 255.255.255.0
# 되돌리기: sudo networksetup -setdhcp "USB 10/100/1000 LAN"
```

### Linux(x86 미니PC)에서 고정 IP
```bash
nmcli con add type ethernet ifname eth0 con-name x2-direct \
  ipv4.method manual ipv4.addresses 10.0.1.2/24
nmcli con up x2-direct
```

## WiFi (ssh 디버깅 전용 — 카메라 스트림 금지)

- 앱으로 로봇 AP 핫스팟 활성화 → 점프호스트 **192.168.88.88** 경유

## ssh 설정 (~/.ssh/config에 추가)

```
# 유선 직결 시 PC2
Host x2
    HostName 10.0.1.41
    User agi
    # 최초 접속 후 ssh-copy-id x2 로 키 등록 권장

# WiFi 점프호스트 경유 (디버깅용)
Host x2-wifi
    HostName 10.0.1.41
    User agi
    ProxyJump agi@192.168.88.88
```

  Phase 6 첫날 PC2에서 `printenv ROS_DOMAIN_ID` 확인 후 동일하게 맞출 것
