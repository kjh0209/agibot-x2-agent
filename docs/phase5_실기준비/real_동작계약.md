# real 모드 동작 계약 (A-3) — 로봇 도착 전 확정본

기능 레지스트리(`robot_agent/features.py`)가 노출을 통제하고, 이 문서는
각 기능의 **실기 구현 계약**을 확정한다. 로봇/견적 회신이 오면 코드가
아니라 이 계약대로 채워 넣기만 하면 되는 상태를 만드는 것이 목적.

## 1. go_to_place — real 경로 (Phase 6.5에서 연결)

### 계약 (LLM 툴 인터페이스는 시뮬과 동일 유지)
- **입력**: `place` (한국어 별칭 → 장소 키 매핑은 지금 것 재사용)
- **동작**: NaviPoint 기반 비동기 이동 — move 비동기와 같은 패턴:
  1. 호출 즉시 `{'ok': '출발했어 …'}` 반환 (시뮬의 동기 완주와 다름 —
     실기는 수십 초 보행을 블로킹하면 채팅이 죽는다)
  2. 진행/도착/실패는 `notify_event`로 통지
     - 도착: "○○ 도착 (실이동 X.Xm)"
     - 실패: "경로 차단/제어권 상실 — 현재 위치 (x, y)"
  3. `stop`/하드정지는 NaviPoint 취소 API 호출로 연결 (이중 경로 유지)
- **장소 사전**: 시뮬 `worlds.py`의 places dict 구조(`pos`,`yaw`,`via`)를
  실기 SLAM 맵 좌표로 채운 `places_real.yaml`(신규)로 대체. 허브/문
  개념은 SLAM 웨이포인트로 그대로 이식.
- **활성화 절차**: SLAM 맵핑 + 장소 등록 완료 후
  `features.py`의 `go_to_place.real_available = True`.

### 선행 조건 (Phase 6.5)
- [ ] 운용 공간 SLAM 맵핑 세션 (리모컨 주행)
- [ ] 장소 사전 구축: "거실" 등 각 장소의 맵 좌표 등록 → places_real.yaml
- [ ] NaviPoint 단발 호출 테스트 (이동/취소/실패 각 1회)
- [ ] 취소 경로가 하드정지 버튼과 연결되는지 검증

## 2. pick_up / put_down — 기본 정책 (a): 실기 v1 제외

- 견적 회신 전 기본값: **핸드 미탑재 가정** —
  `features.py`에 `real_available: False`로 이미 반영됨.
  효과: real 모드에서 툴 자동 숨김 + 프롬프트가 "핸드가 없다"로 전환
  + 요청 시 솔직히 거절.
- 핸드 포함 확정 시 (정책 (b)):
  - HandCommand 인터페이스 조사 착수 (토픽/서비스 스키마, 파지 프리셋)
  - 시뮬 의미론 이식: 도달 게이트(0.95m) → 실기 도달 판정,
    실착지 보고 → 파지 성공/실패 센서 피드백
  - 비전 기반 파지 자세 추정이 필요해지면 별도 미니 프로젝트로 분리
    (일정에 미리 반영)

## 3. sit_down / stand_up — 실기 전제

- 인터페이스는 parity (McAction 2000/2005 — 시뮬과 동일 코드).
- 실기 물리 전제 확인 항목 (Phase 6 안전 체크리스트에 추가됨):
  - [ ] SDK 문서에서 SIT_DOWN의 물리 전제 확인: 바닥 착석인지 /
        의자 높이 요구인지 / 평지 요구인지
  - [ ] **갠트리(매달린 상태)에서 SIT_DOWN 호출 금지 여부** 확인 —
        확인 전까지 갠트리 단계에서는 sit_down을 실행하지 않는다
  - [ ] 착석 상태에서 velocity 게이트가 실기에서도 닫히는지 확인
- **소파 도킹(후진 밀착)은 시뮬 트릭** — 실기 v1에서는 "제자리 착석"
  으로 단순화. 프롬프트의 "소파를 등지고 앉는 흐름" 문구는 features
  레지스트리의 go_to_place 비활성화와 함께 자동으로 사라짐.

## 4. 하드와이어 정지 — real 소스 정책 (A-2① 반영됨)

- sim: 백엔드가 `rc` 소스로 velocity 0 발행 (목의 기본 등록 소스)
- real: 백엔드가 **등록된 `agent` 소스**로 velocity 0 발행 —
  실물 리모컨(진짜 rc)의 중재를 침범하지 않음. 물리 리모컨은
  이와 독립인 3중 정지 경로.
- Phase 7 검증 항목: 에이전트 이동 중 실물 리모컨 개입 → 에이전트
  정지 발행 → 리모컨 우선권 유지 확인 (카오스 시나리오 실기판)

## 5. 모드 전환/모션 완료 — 폴링 계약 (A-2②③ 반영됨)

- `ensure_mode`: SetMcAction 후 GetMcAction 폴링으로 **도달 확인**
  (5s 타임아웃). 시뮬 목은 즉시 통과, 실기는 자세 전환 시간 흡수.
- `play_motion`: 고정 sleep 제거 — 모드가 프리셋 실행으로 바뀌었다
  STAND로 복귀하면 완료로 판정 (12s 상한). 모드 무변화 구현(시뮬 목)은
  2.5s 폴백. 실기에서 프리셋 실행 중 모드 값이 실제로 어떻게 변하는지
  Phase 7 첫 갠트리 세션에서 확인 후 필요 시 판정 조건 갱신.
