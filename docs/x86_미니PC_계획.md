# x86 미니PC 계획 (선택 지출 20~30만원 — 승인 시 실행)

## 왜 필요한가

공식 MuJoCo 시뮬(aima-sim-app)은 클로즈드소스 모듈에 AVX가 박혀 있어
Apple Silicon(Rosetta)에서 영구 실행 불가 (진행상황 4-1 ⑩). AVX를 지원하는
x86-64 리눅스 머신이 있으면:

1. **공식 시뮬 원본 구동** — 이슈3 해소
2. **공식 시뮬 × 우리 에이전트 통합 테스트** — McMock 의미론이 벤더
   구현과 일치하는지 교차 검증 (실기 전 마지막 소프트웨어 관문)
3. **공식 RL 보행 데모** — locomotion 명령에 실제 보행 물리 (데모 퀄리티 ↑)
4. Phase 6의 개발 호스트로 그대로 전환 (버리는 투자 아님)

## 요구 사양

- CPU: AVX2 지원 x86-64 (2015년 이후 인텔/AMD면 사실상 전부. N100도 AVX2 지원)
- RAM 16GB 권장 (8GB 가능), SSD 256GB+, 유선 랜 포트 필수(실기 직결용)
- 후보: 중고 미니PC(NUC류, 10만원대) / 신품 N100 미니PC(15~25만원)
- OS: Ubuntu 22.04 LTS 네이티브 설치 (SDK 공식 요구사항)

## 도착 후 실행 순서 (반나절)

1. Ubuntu 22.04 설치 → ROS 2 Humble + 의존성
   (scripts/setup_sim.sh가 그대로 재사용됨 — amd64용으로 작성돼 있음)
2. `sdk/downloads/*.zip` 복사 → 해제 → `x2_rl_deploy` colcon 빌드
3. `start_sim.sh -s` → `lx2501_3_t2d5` — **이번엔 AVX가 있어 그냥 돌아감**
4. 우리 스택(에이전트+채팅 앱)을 같은 머신 또는 Mac에서 실행,
   토픽/서비스가 공식 시뮬과 맞물리는지 확인
   - 예상 차이점 체크리스트: McAction 전이 규칙 실제 거동,
     SetMcPresetMotion 응답 코드, locomotion 게이트 타이밍,
     카메라 토픽 유무(공식 시뮬이 카메라를 내보내는지 — 안 내보내면
     우리 x2_sim 카메라만 병행 실행)
5. 차이 발견 시 McMock을 벤더 거동에 맞춰 수정 → 커밋
