2. 시뮬 구간(Phase 0~4) 지출 흐름과 절약 원칙
----------------------------------------------------------------
유일한 반복 지출 = Claude API 요금. 아래 원칙을 지키면
개발 기간 전체(3~6주)를 5만~15만원 안에서 끝낼 수 있다.

  a. 개발 반복 루프는 Haiku 4.5($1/$5 per 1M토큰)로 돌린다.
     노드 배선·툴 콜 동작 확인에는 최상위 모델이 필요 없다.
     동작이 잡히면 데모용으로 Sonnet 5($3/$15, 2026-08-31까지
     인트로 $2/$10)로 올린다. 판단 품질이 아쉬울 때만 Opus 5
     ($5/$25)를 시험한다.
  b. 프롬프트 캐싱: 시스템 프롬프트·툴 정의를 고정하고
     cache_control 적용 → 반복 입력이 정가의 ~10%.
  c. 이벤트 기반 호출: 메시지가 왔을 때만 API 호출. look은
     캐시된 최신 프레임 재사용. "초당 N회 폴링" 구조는 비용을
     수십 배로 만든다 — 절대 금지.
  d. 이미지 다이어트: 1024px 1장 ≈ 1,400토큰. 평소 1장만
     첨부하고, 링버퍼 3장 전송은 "방금 뭐 지나갔어?" 같은
     시간 맥락 질문에만.
  e. 청구 대시보드를 주 1회 확인. 크레딧 선불 + 자동충전 OFF
     구조라 실수해도 충전액 이상은 나가지 않는다.

  감각치(캐싱 적용 기준):
  - Haiku 개발 루프: 턴당 ~5원 → 하루 300턴 테스트해도 ~1,500원
  - Sonnet 데모: 턴당 15~30원 → 데모 1시간(100턴) ~2,000~3,000원

  자체 채팅 앱 관련 비용: 0원.
  - React 웹 + rosbridge/FastAPI + SQLite 전부 무료.
  - 폰에서 쓰고 싶으면 PWA(무료). 외부 접속은 Tailscale(무료).
  - 앱스토어 배포용 네이티브 앱은 불필요 (하게 되더라도 실기
    이후 결정. Apple 개발자 계정 연 $99는 지금 쓸 이유 없음)

3. 실기 직전에 준비해둘 목돈 (Phase 5 진입 조건)
----------------------------------------------------------------
시뮬이 완성됐고 견적이 도착했을 때, 아래가 준비돼 있어야
Phase 5로 넘어갈 수 있다. 미리 "쓰는" 게 아니라 "확보"해둘 금액:

  1) X2 Ultra 본체 + 배송 + 세금 ....... 4,300만~6,500만원
     - 참고 기준: X2 표준형 공식가 $24,240(약 3,400만원),
       시리즈 시작가 $27,300~. Ultra는 견적 전용이며 상위 구성
       (+Orin NX 157TOPS, LiDAR, RGB-D, 스테레오/후면 카메라,
       5G)이라 4,000만~6,000만원대 각오.
     - 배송 $500~3,000 + 수입 부가세 10% + 관세 0~8%.
     - 견적서를 받으면 이 항목의 불확실성이 거의 사라진다.
  2) 전동 갠트리(호이스트) + 리프팅 링 ..... 80만~300만원
     - 포장에 미포함. SDK 테스트 시 매달아 시작이 공식 권장.
  3) 안전 매트/펜스 ........................ 10만~50만원
  4) 수리 예비비 (권장) .................... 200만~500만원
     - 낙상 1회 = 관절 모터/헤드 센서(LiDAR·카메라 집중) 파손
       가능. 예비비가 있어야 안전 절차를 서두르지 않게 된다.
     - 견적 단계에서 AS·워런티의 낙상 포함 여부 확인 필수.
  5) (선택) 예비 배터리 .................... 견적 문의
     - 421Wh, 보행 약 2h, 충전 1.5h. 퀵스왑 지원이라 1개
       여분이 있으면 개발 세션이 안 끊긴다.

  실기 준비금 합계: 약 4,600만 ~ 7,400만원
